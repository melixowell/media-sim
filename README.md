# Главред (Telegram Mini App)

Мини-игра для Telegram в жанре симулятора главного редактора радиостанции.

## Что обновлено
- Более выразительный визуальный стиль: glassmorphism-карточки, анимированный фон, прогресс-бары, плавные переходы.
- Длинный сюжет на 10 игровых дней вместо короткой демо-сессии.
- Несколько вариантов финала в зависимости от итоговых метрик станции.
- Интеграция с Telegram WebApp API (`ready`, `expand`, `MainButton`, `sendData`).

## Локальный запуск
```bash
python3 -m http.server 4173
```

Откройте: `http://localhost:4173`

## Подключение к боту
1. Создайте бота через @BotFather.
2. Настройте `Menu Button` на URL опубликованного приложения (HTTPS).
3. Разместите `index.html`, `styles.css`, `app.js` на вашем хостинге.
4. В обработчике бота принимайте `web_app_data`.
